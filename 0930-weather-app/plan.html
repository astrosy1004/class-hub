01배경과 목표

날씨가 바뀌면 현장의 위험도 바뀝니다

폭염·한파·강풍·비·미세먼지는 공사 현장 사고의 직접적인 원인이 되지만, 현장에서는 날씨 앱과 안전 규정을 따로 찾아봐야 합니다.

1정보가 흩어져 있음

날씨는 날씨 앱에, 작업 중지 기준은 법령·가이드 문서에 따로 있어 바쁜 아침 조회 시간에 함께 확인하기 어렵습니다.

2기준이 숫자로 되어 있음

"순간풍속 10m/s", "체감온도 33℃" 같은 기준을 오늘 날씨와 직접 비교해 판단해야 합니다.

3전달이 번거로움

관리자가 확인한 내용을 근로자에게 단톡방·구두로 다시 전달해야 합니다.

목표 — 지역 하나만 검색하면 오늘의 위험 기상과 지켜야 할 안전수칙을 한 화면에서 보고, 링크·QR로 바로 공유할 수 있게 한다.

02주요 기능

다섯 가지 핵심 기능

현장 관리자와 근로자가 출근 직후 1분 안에 오늘의 위험과 대응 수칙을 확인하는 것을 기준으로 기능을 정했습니다.

지역 기반 날씨 조회

구 단위 검색("성남시 분당구")과 현재 위치 조회. 현재·시간별·7일 예보와 미세먼지 등급.

날씨별 안전수칙

더위·추위·강수·강풍·미세먼지 5개 분류, 분류별 위험 요인과 핵심 수칙 5가지.

위험 단계 자동 판정

공식 기준값으로 관심·주의·경고·위험 4단계를 판정해 오늘 주의할 기상을 맨 위에 표시.

위험 기상 알림

분류별로 켜고 끄는 알림. 화면을 열어 둔 동안 30분마다 다시 확인.

즐겨찾기 현장

자주 보는 현장을 저장하고, 로그인하면 최근 조회 지역을 계정에 보관.

현장 공유

링크 복사, QR코드(현장 게시판 부착용), 휴대폰 공유 창으로 카카오톡 전달.

03사용자 흐름

검색 한 번으로 안전수칙까지

모든 화면은 주소의 # 뒷부분으로 바뀌어(#home, #weather, #rules, #rule/heat, #alerts) 휴대폰 뒤로가기와 공유 링크가 그대로 동작합니다.

현장 관리자

아침 TBM 전에 현장 지역을 조회 → 오늘의 위험 단계 확인 → QR코드를 출력해 게시하거나 단톡방에 링크 공유.

현장 근로자

공유받은 링크를 열면 그 현장의 안전수칙 화면이 바로 열림 → 카드를 눌러 상세 수칙 확인.

04화면 구성 (목업 1/3)

메인 화면

공사 현장 배경 위에 검색창과 현재 위치 버튼을 두고, 아래로 최근 조회 지역 · 바로가기 · 전국 현장 날씨 · 안전수칙 가이드를 이어 배치했습니다.

1메인 · 검색

지역명 검색(구 단위 지원)과 현재 위치 조회, 최근 조회 지역 칩.

2메인 · 카드

바로가기 4칸, 전국 7개 도시 날씨 카드(위험 요약 포함), 날씨별 안전수칙 가이드 배너.

04화면 구성 (목업 2/3)

날씨 정보 · 안전수칙 · 상세 수칙

날씨 화면에서 오늘의 위험을 먼저 보여주고, 안전수칙 화면에서 분류별 수칙을, 상세 화면에서 위험 요인과 단계별 수칙을 안내합니다.

3날씨 정보

현재 날씨 · 체감온도 · 미세먼지 등급, 오늘 주의할 기상, 습도·강수확률·풍속, 시간별·주간 예보.

4안전수칙

오늘 날씨 요약, 분류 탭(해당 분류에 빨간 점), 오늘의 주요 안전수칙 카드.

5상세 안전수칙

분류별 작업자 일러스트, "이런 위험이 있어요", 번호 매긴 핵심 수칙 5가지와 참고 기준.

04화면 구성 (목업 3/3)

알림 설정 · 공유

위험 기상 알림은 분류별로 켜고 끌 수 있고, 공유는 받는 사람이 같은 지역의 안전수칙 화면을 바로 열 수 있는 링크로 만듭니다.

6알림 설정

위험 기상 특보 알림 스위치, 폭염·한파·강수·강풍·미세먼지 분류 선택.

7공유하기

링크 복사 · QR코드 생성 · 카카오톡 공유(휴대폰 공유 창), 공유 미리보기.

공유 링크 형식

weath-app-sykim.web.app/?lat=37.5172&lon=127.0473&name=서울특별시 강남구#rules

열면 좌표로 날씨를 다시 조회해 그 시점의 최신 날씨로 안전수칙을 보여줍니다. 지역 이름은 글자로만 표시해 악성 코드 삽입을 막습니다.

05위험 판정 기준

공식 기준값으로 4단계 판정

오늘(현재값 + 오늘 하루 예보)을 기준으로 분류별 단계를 정하고, 위험한 순으로 정렬해 보여줍니다.

분류판정 값단계 기준근거
더위체감온도 최고관심31℃ 주의33℃ 경고35℃ 위험38℃고용노동부 온열질환 예방 가이드
추위최저기온관심0℃ 주의-12℃ 경고-15℃기상청 한파특보 기준
강수강수량 · 강수확률 · 날씨코드관심1mm·확률 60% 주의30mm·뇌우 경고70mm산업안전보건기준 규칙 (철골작업 중지: 강우 1mm/h)
강풍순간풍속 · 평균풍속 최고주의순간 10m/s 경고순간 20m/s · 평균 14m/s산업안전보건기준 규칙 (타워크레인 작업 제한)

※ 기상청 공식 특보가 아니라 Open-Meteo 예보값으로 판정하는 참고 정보입니다. 기준값과 수칙 문구는 js/safety-rules.js 위쪽 데이터에만 있어, 현장 안전관리자의 검토 의견을 코드 수정 없이 반영할 수 있습니다.

08테스트 · 품질 계획

배포 전 확인 기준

빌드·테스트 도구가 없는 정적 사이트이므로, 화면별 체크리스트와 실기기 확인으로 품질을 관리합니다.

✓기능

  • "서울시 강남구", "성남시 분당구", "해운대구" 검색 시 해당 구 날씨
  • 현재 위치 허용 시 구 이름으로 조회, 거부 시 안내 문구
  • 즐겨찾기 추가·삭제, 새로고침 후 유지
  • 공유 링크·QR로 열면 같은 지역 안전수칙 화면

✓화면 · 호환성

  • 375px 폭에서 가로 스크롤 없음
  • 삼성 인터넷 · 크롬 · 사파리에서 아이콘·일러스트 표시
  • 배포 후 휴대폰 새로고침 시 새 버전 반영 (no-cache 헤더)
  • 콘솔 오류 없음

✓예외 상황

  • 네트워크 끊김 시 오류 안내, 화면 깨짐 없음
  • 미세먼지 API 실패 시에도 날씨·수칙은 표시
  • Firebase를 못 불러와도 조회 기능은 동작

✓보안

  • Firestore: 본인 uid 경로만 읽기/쓰기
  • API · 공유 링크의 글자는 모두 이스케이프 후 표시
  • API 키가 필요한 서비스는 사용하지 않음

09리스크와 대응

알려진 한계와 대응 방안

!예보값과 공식 특보의 차이

Open-Meteo 모델값이라 기상청 특보·에어코리아 측정값과 다를 수 있음.

화면에 "참고용" 고지 · 9단계에서 공식 데이터 연동

!알림은 화면을 연 동안만

앱을 닫으면 알림이 오지 않음. 안드로이드 크롬은 화면 안 알림으로 대체.

8단계에서 PWA + Firebase Cloud Messaging 푸시 알림

!무료 API 이용 제한

Nominatim은 초당 1회 이하 정책. 사용자가 늘면 제한될 수 있음.

사람이 검색할 때만 호출 · 실패 시 Open-Meteo로 자동 재시도

!브라우저 캐시로 구버전 표시

배포 직후 휴대폰에서 예전 CSS·JS가 섞여 화면이 깨진 사례 발생 (10.01).

no-cache 헤더 적용 · 파일 주소에 버전(?v=) 표기 — 해결됨
