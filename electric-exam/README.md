# 전기기사 필기 합격 플래너

2027년 2월 28일 전기기사 1차(필기) 시험에 맞춘 시험 준비 웹앱입니다. 파일 하나(`index.html`)로 동작합니다.

- 배포 주소: https://astrosy1004.github.io/class-hub/electric-exam/
- Claude 버전: https://claude.ai/artifact/VoEW8TPXNx5eHi7QJoGXPn (AI 요약 노트 자동 작성 · 계정 저장)

## 기능

- **오늘**: D-day, 오늘 할 일, 밀린 과제, 과목별 진도, 최근 모의고사 점수
- **학습 계획**: 시험일 · 시작일 · 하루 공부 시간 · 수준 · 복습 요일로 이론 1회독 → 기출 회독 → 실전 모의고사 계획 자동 생성, "남은 과제로 오늘부터 다시 짜기", 점수 기록(과락 8문항 · 평균 60점 판정)
- **영상 추천**: 단원별 YouTube 검색 바로가기(개념 강의 · 기출 풀이 · 최신순), 확인한 무료 공개 강의, 내 영상 저장
- **요약 노트**: Claude 요약 노트 생성(Claude 버전), 이 주소에서는 프롬프트 복사 → Claude에 붙여넣기 → 결과 저장, 과목별 핵심 공식 카드
- **시험 정보**: 과목 · 합격 기준 · 2027 출제기준 · 일정 확인 링크

## 저장

GitHub Pages 주소에서는 진도 · 노트 · 점수가 **이 브라우저(localStorage, 키 `eeplan.v1`)에만** 저장됩니다. Claude 버전에서 열면 Claude 계정에 저장되며, 두 곳의 기록은 서로 이어지지 않습니다.

## 수정 방법

`index.html` 의 `<script>` 안 데이터 배열을 고칩니다.

- `BLOCKS`: 과목 블록과 단원 목록 (`[단원 이름, 분량(하루 단위 수)]`)
- `PICKS`: 추천 공개 강의
- `CARDS`: 과목별 핵심 공식 카드 (KEC 수치는 시험일 기준 최신 고시본으로 확인)
- 과목 색은 KEC 전선 식별색(L1 갈 · L2 흑 · L3 회 · N 청 · PE 녹황)을 따릅니다.
