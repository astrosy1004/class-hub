# K-뷰티 패스포트 (MVP 프로토타입)

외국인 여행객이 서울의 K뷰티스토어 · K약국 · 피부과 · 성형외과 · 스파를 **지도에서 찾고, 비교하고, 자기 언어로 예약**하는 플랫폼의 MVP 화면입니다.
기획 내용은 [`k-beauty-tourism-development-plan.md`](./k-beauty-tourism-development-plan.md) (개발계획서) 를 따릅니다. 계획서의 **2단계(MVP)** 범위를 백엔드 없이 정적 사이트로 먼저 구현했습니다.

## 화면 구성 (`목업화면.png` 기준 모바일 웹앱)

하단 탭바(홈 · 지도 · 탐색 · 찜 · 내 여행)로 이동하는 한 페이지 웹앱입니다. 주소의 `#/...` 로 화면이 바뀝니다.

| 화면 | 주소 | 내용 |
| --- | --- | --- |
| 스플래시 | (처음 열 때) | 서울 풍경 일러스트, 언어 선택, 시작하기 |
| 홈 | `#/home` | 지역 선택 · 설정(언어/통화/다크 모드) · 알림, 카테고리, 내 주변 인기, 여행자 추천 코스 |
| 지도 | `#/map` | 검색창 · 필터, 카테고리 칩, 핀 지도, 기준 위치 바꾸기, 선택한 장소 카드 |
| 탐색 | `#/explore` | 검색 · 카테고리 · 평점/영업 중/예약 가능 · 필터 시트(외국어 · 가격대 · 기준 위치 · 정렬) |
| 찜 | `#/saved` | 찜한 장소 목록 |
| 내 여행 | `#/trips` | "○○ 뷰티 데이" 헤더, 날짜별 예약 타임라인, 지도에서 경로 보기, 예약 관리 |
| 장소 상세 | `#/place/<id>` | 대표 이미지 · 찜 · 공유, 특징 아이콘, 인기 서비스, 상세 정보, 정책, 리뷰, 하단 예약하기 |
| 코스 | `#/course/<id>` | 코스 타임라인, 단계별 예약, 지도에 경로 표시 |

사진은 아직 없어서 카테고리 색 그라데이션 + 아이콘 일러스트로 대신합니다.

## 파일

- `index.html`: 앱 틀(화면 섹션 · 탭바)과 시트(설정 · 알림 · 필터 · 예약 · 리뷰)
- `assets/styles.css`: 디자인 (코랄 테마, 색상은 `:root` 변수, 다크 모드는 `[data-theme="dark"]`, 글꼴은 Pretendard + DM Serif Display)
- `assets/app.js`: 최상단 데이터 배열 + 다국어 문구 → 아이콘 · 라우터 · 화면별 그리기 · 예약 · 리뷰
- `assets/logo.svg`: 로고 겸 파비콘
- `목업화면.png`: 화면 목업, `k-beauty-tourism-development-plan.md`: 개발계획서

## 구현된 기능 (계획서 대비)

| 계획서 항목 | 이 버전 |
| --- | --- |
| 4.1 다국어 · 통화 | 한국어 · 영어 · 중국어 · 일본어 UI, KRW · USD · CNY · JPY 가격 표시(고정 환율) |
| 4.2 지도 기반 검색 | 지역(명동 · 강남 · 홍대 · 성수) · 카테고리 · 평점 · 영업 중 · 예약 가능 · 외국어 · 가격대 필터, 역/관광지/공항버스 기준 거리 정렬, 마커 ↔ 목록 연동 |
| 4.3 상세 페이지 | 소개 · 운영시간 · 휴무 · 지원 언어 · 메뉴/시술 가격과 소요시간 · 취소·환불 정책 · 의료 안내 · 리뷰 · 길찾기(Google/Kakao) |
| 4.4 예약 | 즉시 예약 / 예약 요청 구분, 날짜 · 시간 슬롯 · 인원 · 서비스 선택, 예약금 10% 표시(결제 미연동), 예약번호 발급, 취소 |
| 4.5 일정 추천 | 지역별 반나절 코스 4개, 도보 이동시간 · 휴무 요일 표시, 지도에 경로 표시 |
| 4.6 신뢰 기능 | 방문 완료된 예약만 리뷰 작성(방문 인증 배지), 인증 제휴 배지, 광고(유료 노출) 표시 |

아직 없는 것(계획서 3단계 이후): 실제 지도 API, 회원 가입, 서버 · DB, 결제 · 환불, 알림, 제휴사 포털 · 관리자.
제휴사 승인과 방문 완료는 **데모 버튼**으로 흉내 냅니다.

## 수정 방법

`assets/app.js` 상단의 데이터 배열을 고칩니다.

- `PLACES`: 장소. `area` · `category` · 좌표(`lat`, `lng`) · `booking`(`instant` | `request` | `walkin`) · `price`(1~3) · `langs` · `hours` · `closed`(0=일요일) · `services` · `reviews`
  - `sponsored: true` 면 추천순 상단에 오고 **광고** 배지가 붙습니다.
  - `name` · `desc` 는 `ko` · `en` 만 넣어도 됩니다. 중국어 · 일본어 화면에서는 영어로 대신 보여줍니다.
- `AREAS`: 지역과 기준 위치(역 · 관광지 · 공항버스 정류장)
- `CATEGORIES`, `POLICIES`(취소 정책), `COURSES`(추천 코스), `CURRENCIES`(환율)
- `I18N`: 화면 문구. 언어를 추가하려면 `LANGS` 와 `I18N` 에 같은 키로 추가합니다.

장소 · 가격 · 리뷰는 모두 **예시 데이터**입니다.

## 저장되는 값 (이 브라우저 localStorage)

`kbeautyLang` · `kbeautyCurrency` · `kbeautyTheme` · `kbeautyBookings` · `kbeautyFavorites` · `kbeautyReviews` · `kbeautyNotifSeen` (스플래시는 sessionStorage `kbeautySplash`)
