# 외국인 여행객 대상 K-뷰티 관광 플랫폼 개발 계획서

## 1. 프로젝트 개요

### 1.1 프로젝트명

**K-뷰티 패스포트(K-Beauty Passport)**

### 1.2 추진 배경

한국을 방문하는 외국인 여행객의 K-뷰티 관심이 높아지고 있지만, 여행객이 신뢰할 수 있는 뷰티 매장과 의료기관을 찾고, 가격과 서비스를 비교하며, 언어 장벽 없이 예약하기는 어렵다. 본 서비스는 K뷰티스토어, K약국, 피부과, 성형외과, 스파를 하나의 지도 기반 플랫폼으로 연결하여 탐색부터 예약, 방문 후 관리까지 지원한다.

### 1.3 프로젝트 목표

- 외국인 여행객이 지역별 K-뷰티 서비스를 쉽게 검색하도록 지원
- 다국어 정보와 예약 기능을 통해 언어·결제 장벽 완화
- 검증된 제휴 매장과 의료기관을 연결하여 신뢰도 확보
- 뷰티 쇼핑, 약국, 시술, 스파를 결합한 여행 일정 제공
- 제휴 수수료와 광고를 기반으로 지속 가능한 수익 구조 구축

## 2. 목표 고객

### 2.1 핵심 고객

- 한국 방문을 계획 중인 외국인 관광객
- 한국에서 화장품을 구매하려는 고객
- 피부 관리 및 비수술 시술에 관심 있는 고객
- 성형외과 상담 또는 수술을 고려하는 고객
- 여행 중 휴식과 웰니스 서비스를 원하는 고객

### 2.2 우선 공략 시장

1. 영어권 관광객
2. 중국어권 관광객
3. 일본어권 관광객
4. 동남아시아 관광객
5. 중동 및 유럽권 관광객

## 3. 서비스 범위

### 3.1 제휴 카테고리

| 카테고리 | 주요 서비스 |
| --- | --- |
| K뷰티스토어 | 한국 화장품, 브랜드 매장, 면세·관광객 전용 상품 |
| K약국 | 일반의약품, 건강기능식품, 외국인 상담 가능 약국 |
| 피부과 | 피부 진단, 레이저, 스킨부스터, 여드름·흉터 관리 |
| 성형외과 | 상담, 시술, 수술 전후 관리, 통역 연계 |
| 스파·웰니스 | 마사지, 찜질스파, 에스테틱, 두피·바디 관리 |

### 3.2 핵심 사용자 흐름

1. 사용자가 여행 지역과 관심 서비스를 선택한다.
2. 지도에서 주변 제휴 매장과 의료기관을 확인한다.
3. 가격, 리뷰, 언어 지원, 운영시간, 시술·서비스 정보를 비교한다.
4. 매장 또는 병원의 상세 페이지에서 예약을 신청한다.
5. 예약 확정, 알림, 길찾기, 방문 후 리뷰 작성을 이용한다.

## 4. 주요 기능

### 4.1 회원 및 다국어 기능

- 이메일, 소셜 계정, 비회원 예약 지원
- 한국어, 영어, 중국어, 일본어 우선 제공
- 통화 단위별 가격 표시
- 자동 번역 기반 상세 설명과 주의사항 제공
- 여행 일정과 예약 내역을 한곳에서 관리

### 4.2 지도 기반 검색

- 현재 위치와 여행지 기준 검색
- 카테고리별 필터: 스토어, 약국, 피부과, 성형외과, 스파
- 가격대, 평점, 운영시간, 언어 지원, 예약 가능 여부 필터
- 지도 마커와 목록을 연동한 검색 화면
- 공항·호텔·관광지 기준 주변 추천
- 도보·대중교통·차량 길찾기 연계

### 4.3 매장·병원 상세 페이지

- 기본 정보, 사진, 메뉴·시술 목록
- 가격 범위 및 소요 시간
- 지원 언어와 통역 가능 여부
- 의료기관의 경우 의료진·진료과목·주의사항 안내
- 이용자 리뷰와 평점
- 예약 가능 시간 확인
- 취소·환불 정책 표시

### 4.4 예약 및 결제

- 즉시 예약 또는 예약 요청 방식 지원
- 날짜·시간·인원·서비스 선택
- 예약금 또는 전액 결제 기능
- 해외 카드 및 간편결제 연동
- 이메일·앱 푸시·메신저 예약 알림
- 예약 변경·취소·환불 처리
- QR 또는 예약번호 기반 방문 확인

### 4.5 여행 일정 추천

- 숙소와 관광지 기반 K-뷰티 코스 추천
- 예시: 명동 화장품 쇼핑 → 피부과 상담 → 스파
- 예시: 강남 성형외과 상담 → 약국 → 호텔 이동
- 이동시간과 예약시간을 반영한 일정 구성
- 날씨·운영시간·휴무일을 반영한 대체 장소 추천

### 4.6 후기 및 신뢰 기능

- 방문 인증 후 리뷰 작성
- 사진·서비스 만족도·언어 만족도 평가
- 부적절한 리뷰 신고 및 관리자 검수
- 제휴기관 인증 배지
- 광고·추천 콘텐츠의 명확한 표시

## 5. 관리자 및 제휴사 기능

### 5.1 제휴사 포털

- 매장·병원 정보 등록 및 수정
- 서비스, 가격, 운영시간, 예약 가능 시간 관리
- 예약 승인·거절·변경 처리
- 매출 및 예약 현황 조회
- 리뷰와 고객 문의 관리

### 5.2 관리자 시스템

- 제휴사 심사 및 승인
- 의료기관과 일반 매장 권한 분리
- 콘텐츠·번역·배너 관리
- 예약·결제·환불 모니터링
- 부정 예약 및 허위 리뷰 관리
- 국가·언어·카테고리별 이용 통계

## 6. 기술 개발 방향

### 6.1 권장 구성

- 웹: 반응형 웹 서비스
- 모바일: 초기에는 모바일 웹 또는 PWA, 이후 iOS·Android 앱 확장
- 서버: 예약·회원·제휴사·결제 API 중심의 백엔드
- 데이터베이스: 사용자, 장소, 서비스, 예약, 리뷰, 결제 정보 관리
- 지도: 국내 지도 API 및 글로벌 지도 서비스 연동 검토
- 번역: 다국어 콘텐츠 관리와 번역 API 연동
- 결제: 해외 카드, 국내 PG, 간편결제 지원

### 6.2 개인정보 및 보안

- 개인정보 최소 수집 및 목적별 동의
- 결제정보는 전문 결제대행사를 통해 처리
- 관리자 계정 다중 인증 및 권한 관리
- 예약·환불·의료 관련 데이터 접근 로그 관리
- 개인정보 처리방침과 이용약관 다국어 제공
- 의료·성형 서비스는 광고 및 중개 관련 법률 검토 후 운영

## 7. 수익화 모델

### 7.1 예약 중개 수수료

제휴 매장 또는 병원에서 발생한 예약·결제 금액의 일정 비율을 수수료로 받는다. 초기에는 입점 장벽을 낮추기 위해 카테고리와 매출 규모에 따라 차등 수수료를 적용한다.

### 7.2 프리미엄 노출 상품

- 지도 상단 노출
- 지역별 추천 매장 영역
- 메인 화면 배너
- 여행 일정 추천 내 우선 노출
- 다국어 콘텐츠 제작 패키지

단, 광고 또는 유료 노출 여부는 사용자에게 명확히 표시한다.

### 7.3 제휴 패키지 판매

- 화장품 쇼핑 패키지
- 피부과 상담 및 관리 패키지
- 스파·웰니스 패키지
- 공항 픽업·통역·컨시어지 결합 패키지
- 호텔·여행사와 공동 판매하는 K-뷰티 여행 상품

### 7.4 제휴 브랜드 및 상품 판매

- 한국 화장품 온라인 사전 주문
- 여행객 호텔 배송 또는 공항 수령
- 제휴 브랜드의 공식 상품 판매
- 개인 맞춤형 화장품 추천 후 구매 연결

### 7.5 B2B 구독 모델

제휴사에게 월 구독형 관리 도구를 제공한다.

- 예약 관리
- 외국인 고객 CRM
- 다국어 메뉴·상세페이지 관리
- 매출·리뷰 분석
- 외국인 고객용 마케팅 리포트

## 8. 단계별 개발 일정

### 1단계: 기획 및 검증 — 1~2개월

- 고객 인터뷰 및 국가별 요구사항 조사
- 제휴 후보 매장·병원 30~50곳 확보
- 서비스 정책, 수수료, 취소·환불 기준 수립
- 법률·의료 광고·개인정보 검토
- 핵심 화면 설계 및 프로토타입 제작

### 2단계: MVP 개발 — 3~4개월

- 다국어 회원·장소 검색
- 지도와 목록 검색
- 장소 상세 페이지
- 예약 요청 및 예약 알림
- 관리자용 제휴사 등록·예약 관리
- 리뷰와 기본 통계

### 3단계: 결제 및 운영 고도화 — 5~6개월

- 해외 결제 연동
- 예약금·환불 처리
- 제휴사 포털
- 쿠폰·프로모션
- 여행 일정 추천
- 영어·중국어·일본어 콘텐츠 확대

### 4단계: 성장 및 확장 — 7개월 이후

- 모바일 앱 출시
- 호텔·여행사·공항과 제휴
- 개인 맞춤형 추천 고도화
- 공항 수령 및 배송 서비스
- 동남아·중동·유럽 시장별 마케팅
- B2B 구독형 상품 출시

## 9. 운영 및 마케팅 전략

### 9.1 고객 확보

- 인천공항·호텔·관광안내소 제휴
- 해외 인플루언서 및 여행 크리에이터 협업
- 검색광고와 SNS 다국어 콘텐츠 운영
- 여행 전 예약 고객 대상 할인 쿠폰 제공
- 방한 관광객 대상 QR 홍보물 배포

### 9.2 제휴사 확보

- 외국인 응대가 가능한 매장 우선 입점
- 초기 제휴사에 무료 등록 및 수수료 우대 제공
- 외국어 메뉴·사진·상세페이지 제작 지원
- 예약 데이터를 기반으로 한 운영 개선 리포트 제공

## 12. MVP 출시 기준

다음 조건을 충족하면 1차 서비스를 출시한다.

- 서울 주요 지역의 제휴 장소 50곳 이상 확보
- 영어·중국어·일본어 기본 서비스 제공
- 지도 검색과 상세 정보 확인 가능
- 예약 요청과 예약 확정 알림 가능
- 관리자에서 장소와 예약을 관리 가능
- 개인정보 처리방침, 이용약관, 취소·환불 정책 공개
- 실제 예약 시나리오와 결제·환불 테스트 완료

## 13. 기대 효과

- 외국인 여행객의 K-뷰티 접근성과 예약 편의성 향상
- 중소형 뷰티 매장과 의료기관의 외국인 고객 확보
- 쇼핑·의료·웰니스가 결합된 체류형 관광 활성화
- 제휴사와 플랫폼 모두가 데이터를 활용한 서비스 개선 가능
- 향후 K-푸드, 한방, 웰니스 관광으로 확장 가능한 기반 마련

## 14. 결론

K-뷰티 패스포트는 외국인 여행객이 한국의 뷰티 서비스를 안전하고 편리하게 탐색하고 예약할 수 있도록 돕는 지도 기반 플랫폼이다. 초기에는 서울의 주요 관광지와 검증된 제휴사를 중심으로 MVP를 출시하고, 예약·결제·다국어 운영을 안정화한 뒤 호텔, 여행사, 공항, 브랜드와의 제휴를 확대한다. 수익은 예약 중개 수수료를 중심으로 하되, 프리미엄 노출, 패키지 상품, 상품 판매, B2B 구독으로 다각화한다.
