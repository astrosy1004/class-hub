# AI Product Master Hub

생성형 AI 프로덕트 마스터 2기 수강생을 위한 수업용 링크 허브입니다.

## 구성

- `index.html`: 웹사이트 본문
- `assets/styles.css`: 디자인 스타일
- `assets/app.js`: 링크 데이터, 검색, 다크 모드, 복사 버튼, 체크리스트

## 수정 방법

링크와 도구 목록은 `assets/app.js` 상단의 데이터 배열에서 수정할 수 있습니다.

중요:
공개 저장소나 GitHub Pages에 배포하면 Zoom PW, LMS 코드, Discord 초대 링크가 외부에 노출될 수 있습니다. 공개 배포 전에는 민감 정보를 제거하거나 “수강생 공지방 확인” 같은 문구로 바꾸는 것을 권장합니다.

## 로컬 확인

`index.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. GitHub 저장소의 Settings > Pages로 이동합니다.
3. Branch를 `main`, 폴더를 `/root`로 선택합니다.
4. 저장 후 배포 주소를 확인합니다.
