# 나의 북마크 모음집

자주 쓰는 AI 도구와 참고 자료를 한곳에 모아둔 개인 북마크 페이지입니다.

## 구성

- `index.html`: 웹사이트 본문
- `assets/styles.css`: 디자인 스타일
- `assets/app.js`: 링크 데이터, 왼쪽 메뉴, 검색, 다크 모드
- `assets/bookmark-hero.png`: 상단 이미지

## 수정 방법

링크와 도구 목록은 `assets/app.js` 상단의 데이터 배열에서 수정할 수 있습니다.

## 제목 후보

- 나의 북마크 모음집
- AI 작업실 북마크
- My Bookmark Desk
- 링크 작업실
- 오늘의 도구함

## 로컬 확인

`index.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. GitHub 저장소의 Settings > Pages로 이동합니다.
3. Branch를 `main`, 폴더를 `/root`로 선택합니다.
4. 저장 후 배포 주소를 확인합니다.
