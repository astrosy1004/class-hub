# 🐍 파이썬 방탈출 — 바이브 코딩 수업 복습 게임

초등학생 대상 **파이썬 바이브 코딩 수업**(기초 문법 · 변수 · 조건문 · Thonny · SDGs 프로젝트 발표)을 마친 뒤,
네온 도시 메타버스 방탈출로 배운 내용을 복습하고 **실시간 결과 확인 · 시상식 · 결과 공유**까지 한 번에 진행하는 정적 웹페이지입니다.

## 구성

| 화면 | 내용 |
| --- | --- |
| 🎫 시작 | 캐릭터(이모지) 고르기, 이름/팀, **수업 코드** 입력(링크로 들어오면 자동 입력) |
| 🌃 네온 시티 맵 | ZEP처럼 캐릭터를 움직여 돌아다님. 네온 테두리·젖은 바닥·비 효과, 🎁 배달 드론 '파이'가 안내 |
| ❗ 문제 물건 (총 18문제) | 물건에 다가가 스페이스바/💬 → 문제 팝업. 📜 기초 문법 · 💧 변수 · 🤪 넌센스 퀴즈 · ♻️ 조건문 · 🛠️ Thonny & 바이브 코딩 → 🌏 SDGs 탈출 금고 |
| 🎉 결과 | 점수·시간·힌트 기록, SDGs 프로젝트 이름 입력, 선생님 화면으로 **자동 전송** |
| 🏆 선생님 화면 (`#awards`) | 수업 코드·학생용 링크, **지금 탐험 중인 팀 실시간 현황**, 순위표, 상 이름 수정, 상장·CSV·텍스트 복사 |
| 🎬 시상식 / 📺 결과 공유 화면 | 특별상 → 동·은·금상 순서로 "두구두구" 발표, 마지막에 시상대 + 전원 결과판 |

조작: ⬆⬇⬅➡ / W·A·S·D 이동, 스페이스바(또는 E·Enter) 문제 풀기·말 걸기, 맵 클릭(터치) 시 그곳까지 자동으로 걸어감.
태블릿·휴대폰에서는 화면에 방향 패드와 💬 버튼이 나옵니다.

문제는 초등학생 눈높이의 3지선다 객관식이 대부분이고, 숫자 입력 2개, 순서 맞추기 1개가 섞여 있습니다.
방의 문제를 모두 풀면 🔑 열쇠 숫자를 얻고, 열쇠 5개가 모이면 금고 문(핑크 레이저)이 열립니다.
금고 비밀번호는 열쇠 숫자를 변수에 담아 더하는 코드의 실행 결과입니다.

### 점수와 상

- 정답 +100, 오답 −5, 힌트 −10, 2번 틀리면 '정답 보기'(그 문제 점수 없음)
- 탈출 보너스 +300, 시간 보너스 최대 +300 (30분에 가까울수록 줄어듦)
- 순위: 탈출 여부 → 열쇠 수 → 점수 → 시간
- **모든 참가자가 상을 하나씩** 받습니다: 1~3등 → 특별상(번개 탈출 · 스스로 해결 · 백발백중 · 포기는 없다) → 나머지는 응원상(SDGs 지킴이 등)

## 수업에서 쓰는 방법

1. 선생님이 상단 🏆(선생님 화면)을 엽니다. **수업 코드**(예: `GD27`)가 자동으로 만들어져요.
2. **🔗 학생용 링크 복사** → 단톡방·클래스룸에 붙여 넣기. 학생은 링크로 들어오면 수업 코드가 자동으로 들어가요.
   (링크 대신 시작 화면의 '수업 코드' 칸에 직접 적어도 됩니다.)
3. 학생이 문제를 풀 때마다 선생님 화면의 **🎮 지금 탐험 중**에 진행 상황이 4초마다 나타나고,
   탈출하면 **📊 순위표**로 자동으로 옮겨집니다. 결과 코드를 복사할 필요가 없어요.
4. **🎬 시상식 시작** (→ / 스페이스 / 클릭으로 진행, Esc 닫기) 또는 **📺 결과 공유 화면**.
5. 📋 결과 텍스트 복사(단톡방 공유), ⬇️ CSV, 🖨 결과표·상장 인쇄(A4 가로, PDF 저장 가능).
6. 다음 수업에서는 **🔄 새 수업 코드**를 누르면 새 반으로 시작합니다.

> 인터넷이 안 될 때(예비용): 수업 코드 없이 하면 결과 화면에 **결과 코드(`PY-…`)** 가 나오고,
> 선생님 화면 '인터넷 없이 모으기'에 붙여 넣으면 됩니다. 같은 컴퓨터에서 한 기록은 자동으로 모입니다.

> 수업 이름·날짜·주는 사람·제한 시간은 선생님 화면의 '수업 정보'에서 바꾸면 상장에 반영됩니다.

## 실시간 결과 저장소 (Firebase)

- 프로젝트: `python-escape-sykim` (Cloud Firestore). SDK 없이 Firestore REST API를 `fetch`로 직접 호출합니다.
- 저장 위치: `pyEscape/{수업코드}/records/{기록ID}` — 이름·점수·열쇠 수 등 게임 기록만 저장(로그인 없음).
- 보안 규칙: [`firestore.rules`](firestore.rules) — 정해진 필드·크기만 쓰기 허용, 삭제·다른 경로 접근 금지.
  규칙을 고친 뒤 이 폴더에서 `firebase deploy --only firestore:rules --project python-escape-sykim`.
- 선생님 화면의 ✖ / 전체 초기화는 **화면에서 숨기기**입니다(서버 기록은 그대로). 서버에서 지우려면
  `firebase firestore:delete pyEscape/수업코드 --recursive --project python-escape-sykim`.
- 기능을 끄려면 `app.js`의 `ONLINE.projectId` 를 `""` 로 비우세요.

## 수정 방법

모든 내용은 `assets/app.js` **최상단 데이터**에 있습니다. 코드를 몰라도 글자만 고치면 됩니다.

- `GAME` — 제목, 소개 문구, 기본 수업 이름
- `SCORE` — 점수 규칙, 정답 보기까지 필요한 오답 수
- `AVATARS` — 고를 수 있는 캐릭터 이모지
- `ROOMS` — 방 5개와 문제 (`key` 는 열쇠 숫자, 문제의 `obj`·`x`·`y` 는 맵에 놓일 물건과 위치)
- `FINAL_ROOM` — 마지막 금고 (`{KEY_LINES}`, `{KEY_SUM}` 등은 열쇠 숫자로 자동 계산)
- `WORLD_MAP` — 맵 모양 (한 글자 = 한 칸: `#` 벽, `.` 광장, `1~6` 방 바닥, `D` 문, `L` 금고 문)
- `NPCS` / `DECOR` — 말 거는 캐릭터와 대사(`drone: true` 면 드론 모양으로 그림), 꾸미기 물건
- `TOP_AWARDS` / `SPECIAL_AWARDS` / `CHEER_AWARDS` / `CERT_TEXT` — 상 이름과 상장 문구
- `ONLINE` — 실시간 결과 저장소 설정
- 맵 네온 색은 `assets/styles.css` 의 `--neon-1` ~ `--neon-6`, `--neon-pink`, `--neon-cyan`

문제 형식:

```js
{ obj: "📜", x: 3, y: 2, type: "choice", q: "질문", code: ["코드 한 줄", "    들여쓴 줄"], options: ["보기1", "보기2", "보기3"], answer: 0, hint: "힌트", explain: "해설" }
{ type: "input",  q: "질문", code: [...], answers: ["정답", "다른 정답"], hint, explain }   // 띄어쓰기·따옴표는 무시하고 채점
{ type: "order",  q: "질문", lines: ["정답 순서 1", "정답 순서 2"], isCode: true, hint, explain }
```
