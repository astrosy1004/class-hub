# 연혁 영상 메이커 (timeline-video)

인물의 과거 → 현재 사진과 주요 사건(기사 요약)을 연도순으로 이어 붙여 유튜브용 영상(mp4/webm)으로 저장하는 정적 사이트입니다.
서버·업로드 없이 브라우저 안에서만 동작합니다.

## 구성

```
timeline-video/
  index.html        # 화면 (미리보기 + 편집 패널)
  assets/styles.css # 색상은 :root / [data-theme="dark"] 변수로 관리
  assets/wiki.js    # 인물 불러오기 (위키데이터·위키백과·위키미디어 공용 API)
  assets/app.js     # 최상단 DEFAULT_PROJECT(예시 데이터), SETTINGS(재생·색상 설정)
  .nojekyll
```

## 인물 불러오기

이름을 검색하면 동명이인 목록에서 인물을 고르고, 아래 정보를 자동으로 채웁니다.

| 항목 | 출처 |
|---|---|
| 생년월일·출생지·정당·학력 | 한국어 위키백과 정보상자 → 없으면 위키데이터 |
| 경력(직책·취임일·퇴임일) | 위키백과 정보상자 `명칭N/취임일N/퇴임일N` + 위키데이터 직책(P39) |
| 장면 설명 | 위키백과 요약문에서 같은 연도·직책이 나오는 문장, 없으면 재임 기간 |
| 사진 | 위키미디어 공용 (이 인물이 찍힌 사진 + 이름 검색), 촬영 연도 기준 자동 배정 |

- 체크한 연혁만 장면이 되고, `장면 만들기` 후에도 장면 편집에서 글·사진을 모두 고칠 수 있습니다.
- 출처 칸에 사진 작가와 라이선스가 자동으로 들어가고, 영상 하단에 표시됩니다.
- 나무위키는 쓰지 않습니다: 브라우저에서 직접 읽을 수 없고(CORS), 자동 수집을 금지하며, 글은 비영리 조건 라이선스(CC BY-NC-SA)라 수익형 영상에 쓰기 어렵습니다.
- 위키백과 글은 CC BY-SA, 공용 사진은 사진마다 라이선스가 다릅니다. 영상 설명란에도 출처를 적어 주세요.

## 사용법

1. (선택) `인물 불러오기`로 이름을 검색해 연혁·사진을 채웁니다.
2. 인물 이름·부제, 화면 비율(가로 16:9 / 쇼츠 9:16), 장면 전환 방식을 고릅니다.
3. 장면마다 연도, 나이, 제목, 기사 요약, 출처, 사진을 입력·수정합니다. (`📷 사진 여러 장으로 추가`로 파일명 순서대로 일괄 추가도 가능)
4. `▶ 미리보기`로 확인한 뒤 `🎬 영상 만들기`를 누르면 재생 시간만큼 실시간 녹화되고, 끝나면 다운로드 버튼이 나옵니다.
5. 배경음악을 고르면 영상에 함께 녹음됩니다. 처음과 끝은 자동으로 페이드됩니다.

## 배경음악

- `assets/app.js` 최상단 `MUSIC` 배열: 위키미디어 공용에 올라온 Kevin MacLeod(incompetech.com) 곡 16개, 분위기별(잔잔·회상 / 다큐·서사 / 밝음·경쾌 / 긴장·뉴스).
- 모두 **CC BY 3.0** — 출처만 표기하면 상업(수익형) 영상에도 쓸 수 있습니다. 곡을 고르면 나오는 출처 문구를 **유튜브 설명란에 꼭 붙여 넣으세요.**
- 곡 추가: 공용 파일 페이지의 원본 URL에서 `https://upload.wikimedia.org/wikipedia/commons/` 뒷부분을 `path`에 넣습니다. 음원 서버가 CORS를 허용해야 녹화에 소리가 들어가므로, 다른 사이트 주소는 쓰지 마세요.
- 내 음악 파일도 올릴 수 있습니다(저작권은 직접 확인).
- Pixabay·유튜브 오디오 보관함 등은 브라우저에서 직접 불러올 수 없어(API·CORS 없음) 목록에 넣지 않았습니다. 거기서 받은 파일은 `내 음악 파일 올리기`로 쓰면 됩니다.

## 채널 이름

`채널 이름`을 입력하면 영상 왼쪽 위에 표시됩니다(비우면 인물 이름). 브라우저에 저장되어 다음에도 유지됩니다.

## 수정 방법

- 기본 예시 내용: `assets/app.js` 최상단 `DEFAULT_PROJECT`
- 인트로 길이·전환 시간·강조 색: `SETTINGS`
- 장면 디자인(글자 크기·위치): `drawSegment()`

## 배포 시 주의

`assets/` 파일을 고쳤으면 `index.html`의 `?v=` 숫자를 하나 올리세요. 그래야 방문자 브라우저가 예전 파일을 쓰지 않습니다.

## 로컬 확인

`index.html`을 브라우저(Chrome/Edge 권장)로 직접 엽니다. 녹화 중에는 탭을 전환하지 마세요.

## 주의 (콘텐츠 제작 시)

- 사진은 저작권·초상권을 확인한 것만 사용하고, 슬라이드의 `출처` 칸에 반드시 표기하세요.
- 기사 내용은 사실 확인 후 요약하고, 단정·비방이 되지 않도록 중립적으로 쓰세요.
- 실제 인물의 얼굴을 AI로 합성·변조하는 기능은 넣지 않았습니다. 과거·현재 **실제 사진**을 올리는 방식입니다.
- 새로고침하면 입력 내용과 사진이 초기화됩니다(저장 기능 없음).
