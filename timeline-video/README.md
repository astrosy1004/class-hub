# 연혁 영상 메이커 (timeline-video)

인물의 과거 → 현재 사진과 주요 사건(기사 요약)을 연도순으로 이어 붙여 유튜브용 영상(mp4/webm)으로 저장하는 정적 사이트입니다.
서버·업로드 없이 브라우저 안에서만 동작합니다.

## 구성

```
timeline-video/
  index.html        # 화면 (미리보기 + 편집 패널)
  assets/styles.css # 색상은 :root / [data-theme="dark"] 변수로 관리
  assets/app.js     # 최상단 DEFAULT_PROJECT(예시 데이터), SETTINGS(재생·색상 설정)
  .nojekyll
```

## 사용법

1. 인물 이름·부제, 화면 비율(가로 16:9 / 쇼츠 9:16), 장면 전환 방식을 고릅니다.
2. 장면마다 연도, 나이, 제목, 기사 요약, 출처, 사진을 입력합니다. (`📷 사진 여러 장으로 추가`로 파일명 순서대로 일괄 추가도 가능)
3. `▶ 미리보기`로 확인한 뒤 `🎬 영상 만들기`를 누르면 재생 시간만큼 실시간 녹화되고, 끝나면 다운로드 버튼이 나옵니다.
4. 배경음악 파일을 고르면 영상에 함께 녹음됩니다.

## 수정 방법

- 기본 예시 내용: `assets/app.js` 최상단 `DEFAULT_PROJECT`
- 인트로 길이·전환 시간·강조 색: `SETTINGS`
- 장면 디자인(글자 크기·위치): `drawSegment()`

## 로컬 확인

`index.html`을 브라우저(Chrome/Edge 권장)로 직접 엽니다. 녹화 중에는 탭을 전환하지 마세요.

## 주의 (콘텐츠 제작 시)

- 사진은 저작권·초상권을 확인한 것만 사용하고, 슬라이드의 `출처` 칸에 반드시 표기하세요.
- 기사 내용은 사실 확인 후 요약하고, 단정·비방이 되지 않도록 중립적으로 쓰세요.
- 실제 인물의 얼굴을 AI로 합성·변조하는 기능은 넣지 않았습니다. 과거·현재 **실제 사진**을 올리는 방식입니다.
- 새로고침하면 입력 내용과 사진이 초기화됩니다(저장 기능 없음).
