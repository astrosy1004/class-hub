검색 화면 개선 목업

지금 화면은 단계 번호 · 버튼 모양이 많아 복잡하고, 무엇을 근거로 분석하는지 보이지 않음. 값은 예시(합정동 베이커리)입니다.

  1. 신뢰 표시 — "2단계면 끝나요" 대신 초록 점 + "서울 427개 동 · 매일 갱신" 데이터 배지.
  2. 번호 삭제 — 단계 번호 · 체크 동그라미를 빼고 카드 제목만. 고른 업종은 타일 모서리 ✓ 로 표시.
  3. 세부 업종 안내 — "더보기" → "＋ 세부 업종 15개".
  4. 지역 확정 표시 — 검색한 동이 행정동으로 확인되면 초록 칸에 "합정동 · 마포구 · 행정동 확인됨".
  5. 가벼운 보조 버튼 — 큰 "현재 위치로 선택" 상자를 글자 버튼으로 줄여 시선을 덜 뺏게.
  6. 분석 내용 미리 보기 — 버튼 위에 생활인구 · 경쟁 점포 · 고객층을 보여 주고, 버튼 안에 "출처와 기준일을 함께 보여 드려요".
  7. 하단 메뉴 — 깔끔한 돋보기 + "검색하기".
