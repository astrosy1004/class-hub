# Life Compass · 나의 나침반

MBTI식 선호 탐색과 성격·기질·가치관·행동 실험을 연결해, 자신에게 맞는 삶의 조건을 발견하도록 돕는 자기이해 웹앱입니다.
`life-compass-webapp-plan.html`(기획서 v1.0)을 바탕으로 만든 MVP입니다.

> 성향 × 가치관 × 현실 조건 → 삶의 방향 실험

## 화면

| 주소 | 화면 | 내용 |
| --- | --- | --- |
| `#/intro` | 소개(랜딩) | 히어로(나선형 막대 배경) · 대시보드 미리보기 · 원칙 숫자 카드 슬라이드. 응답이 없을 때는 `#/home` 에서도 이 화면이 나옴 |
| `#/home` | 대시보드 | 성향 지도 · 이번 주 회복감 · 응답 편향 · 맞을 가능성이 높은 조건 · 진행 상황 |
| `#/explore` | 탐색 | 8단계 목록 (에너지 → 자극과 감정 → 정보 처리 → 의사 결정 → 생활 리듬 → 핵심 가치 → 강점 패턴 → 삶의 방향) |
| `#/step/1`~`8` | 단계 진행 | 5점 척도 문항 · 가치 카드(3~5개) · 성찰 메모 · 삶의 모델 비교 |
| `#/result` | 결과 리포트 | 레이더 차트 · 축별 점수와 응답 변동 범위 · 일관성/편향 · 결과 저장(이전 결과와 비교) |
| `#/experiment` | 삶의 실험 | 4주 실험 설계 → 매일 기록(몰입도·회복감·스트레스·지속 가능성) → 재해석(유지·수정·중단) |
| `#/trust` | 근거·안내 | 근거 층위 · 안전장치 · 해석의 한계 · 검증 계획 · 수정 이력 · 문항 출처 · 데이터 내보내기/가져오기 |

## 구성

- `index.html`: 상단 메뉴, 화면이 그려지는 `#app`, 안전 안내 푸터
- `assets/styles.css`: 디자인 (색상은 `:root` 변수, 다크 모드는 `[data-theme="dark"]`, 글꼴은 Pretendard CDN)
- `assets/app.js`: 상단 데이터 배열 + 점수 계산 + 해시 라우터 + 화면 그리기
- `assets/logo.svg`: 나침반 로고 겸 파비콘
- `life-compass-webapp-plan.html`: 원본 기획서 (슬라이드)

## 수정 방법

`assets/app.js` 상단 배열만 고치면 됩니다.

- `AXES`: 성향 축 5개(자율성·관계·변화·구조·몰입)와 높을 때/낮을 때 해석 문구
- `STEPS`: 8단계. 문항은 `{ id, text, axis, reverse, basis, ref }`
  - `reverse: true` 는 역채점 문항 (응답 일관성 계산에 쓰임 — 축마다 1개 이상 두세요)
  - `basis`: `research`(연구 근거) · `prelim`(예비 근거) · `reflect`(성찰 제안)
- `VALUES`: 6단계 가치 카드
- `LIFE_MODELS`: 8단계 삶의 모델. `target` 은 축별 기대 점수, `values` 는 잘 맞는 가치, `actions` 는 기본 실험 행동
- `LOG_METRICS`, `EXPERIMENT_DAYS`: 실험 기록 항목과 기간
- `CHANGELOG`: 근거·안내 화면에 공개되는 문항 수정 이력 — 문항을 바꾸면 한 줄 추가하세요
- `LANDING`: 소개 화면 배지·제목·설명 문구
- `LANDING_STATS`: 소개 화면 숫자 카드. `value` 는 위 데이터에서 계산되므로 문항·모델 수가 바뀌면 자동 반영
- `SHOWCASE_RECOVERY`: 소개 화면 대시보드 미리보기의 예시 그래프 값 (실제 데이터 아님)

## 점수 계산

- 축 점수 = 해당 축 문항(역채점 반영) 평균을 0~100으로 환산. 70 이상 강함 · 60 이상 약간 강함 · 41~59 중립 · 31~40 약간 약함 · 30 이하 약함
- 응답 변동 범위 = 1.96 × 표준편차 / √문항 수 (참고값)
- 응답 일관성 = 같은 축의 정채점·역채점 문항 평균 차이로 계산
- 응답 편향 = 한 값 몰아 답하기 · 양 끝 응답 · 중간값 위주 비율
- 삶의 모델 적합도 = 100 − 축 점수와 기대 점수의 평균 차이 + 겹치는 가치 1개당 3점

표본 기준(규준)이 없는 예비 버전이며, 임상 진단 도구가 아닙니다.

## 데이터 저장

모든 응답·결과·실험 기록은 서버 없이 **이 브라우저 localStorage** 에만 저장됩니다.

- `compassState`: 응답, 가치, 메모, 저장한 결과, 실험 기록
- `compassTheme`: 다크 모드 설정

근거·안내 화면에서 JSON 내보내기/가져오기/전체 삭제를 할 수 있습니다.
