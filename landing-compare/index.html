같은 목적, 다른 창고 SaaS 랜딩 페이지

두 개의 서로 다른 브리프로 물류 SaaS 랜딩 페이지를 각각 만들었습니다. 아래에서 두 결과물을 열어 보고, 배경색·강조색·서체·여백 등 여섯 가지 축으로 무엇이 어떻게, 왜 달라졌는지 정리합니다.

루프(LOOP) — “물류 SaaS 랜딩 페이지. 깔끔하고 모던하게.” 영업용 소개 페이지에 가까운 열린 브리프.

Palletto — 창고 관리자가 하루 6시간 이상 보는 사내 대시보드. 신뢰감, 저피로, 다크 모드 우선, 표와 숫자 중심의 고밀도.

여섯 가지 차이

01

배경색과 테마 전략

루프
#F2F4F7 · 쿨 오프화이트

라이트가 기본. 우상단 토글로 다크 전환, prefers-color-scheme로 OS 설정도 존중.

Palletto
#0F1419 · 다크 청회색 (순흑 아님)

다크가 기본. :root 자체가 다크라 OS가 라이트여도 다크로 열림. 라이트는 토글로만.

왜 — 루프는 처음 방문하는 잠재 고객을 위한 페이지라 밝고 개방적인 인상이 우선입니다. Palletto는 관리자가 교대 내내 응시하는 화면이라, 눈부심·잔상을 줄이려고 순백/순흑을 피하고 대비를 낮춘 다크를 기본값으로 못 박았습니다. 브리프의 “다크 모드 우선”을 “다크가 디폴트”로 해석한 결과입니다.

02

강조색과 의미 색

루프
accent #2358C6 good warn

채도 높은 코발트 블루. 버튼·링크·CTA에서 시선을 끌어 행동을 유도.

Palletto
accent #54B3A8 good warn crit

채도를 낮춘 청록 하나. 경고색(호박·벽돌빨강)도 저채도라 장시간 봐도 자극이 적음.

왜 — 루프의 파랑은 플라스틱 파렛트를 연상시키는 브랜드색이자 전환(conversion) 장치입니다. Palletto는 “빨간 게 없으면 정상”이라는 사용 방식을 전제로, 색이 피로를 유발하지 않도록 전 팔레트의 채도를 끌어내렸습니다. 또한 Palletto는 상태를 색 + 형태(● ▲ ■)로 이중 표기해 저조도·색각 이상 환경에서도 구분되게 했습니다.

03

서체

루프 · Archivo + IBM Plex Sans KR
LOOP 1,240,000장
Archivo 700 — 사이니지 계열, 헤드라인 크게

창고 표지판 같은 기하학적 그로테스크. 히어로 제목을 큼직하게 써서 마케팅 임팩트.

Palletto · Hanken Grotesk + Gothic A1 + JetBrains Mono
Palletto UPH 142
Hanken Grotesk 700 — 휴머니스트, 저피로 · 수치는 JetBrains Mono

부드러운 휴머니스트 그로테스크로 장시간 가독성 확보. 모든 숫자는 고정폭이라 자릿수가 세로로 정렬됨.

왜 — 루프는 한 번 훑고 지나가는 페이지라 디스플레이 서체의 개성과 큰 스케일이 유리합니다. Palletto는 표와 숫자를 정확히 읽어야 하는 도구라, 본문은 눈이 편한 휴머니스트 계열을 쓰고 데이터는 전용 고정폭 서체(JetBrains Mono)에 tabular-nums를 걸어 “표를 훑을 때 값의 크기가 바로 보이게” 했습니다.

04

여백과 데이터 밀도

루프 · 넉넉하게
재고 정확도 99.42 피킹 UPH 142 적치율 87.30

섹션 패딩 clamp 3.5–6rem, 본문 폭 ~65자, 기준 폰트 16px. 요소 사이에 숨 쉴 공간.

Palletto · 촘촘하게
재고 정확도 99.42 피킹 UPH 142 적치율 87.30

테이블 셀 상하 패딩 9px, 라인 좁게, 기준 폰트 15px, KPI는 1px 헤어라인 그리드. 1080p에 재고 28행 목표.

왜 — 루프의 여백은 “읽기 편한 소개 문서”를 위한 것이고, Palletto의 압축은 “한 화면에 최대한 많은 행”을 위한 것입니다. 관리자는 스크롤을 최소화하고 싶어 하므로, 행 높이·여백·폰트 크기를 모두 조금씩 줄여 정보 밀도를 높였습니다. 같은 3줄이 Palletto에서 눈에 띄게 짧게 들어갑니다.

05

히어로와 레이아웃 구조

루프

일러스트 히어로 + 마케팅 섹션: 지표 띠 → 기능 4 → 풀 사이클 5단계 → 규격표 → 포털 미리보기 → 후기 → 요금. CSS로 그린 등각 투영 파렛트 스택.

Palletto

대시보드가 곧 히어로: 실시간 패널(현재 지표·지연 오더·시간대별 막대) → KPI 밴드(스파크라인) → 데이터 테이블 → 알림 피드 → 연동 → 요금. 전부 실데이터 형태의 목업.

왜 — 열린 브리프의 루프는 “무엇을 해주는 서비스인가”를 설명해야 해서 일러스트와 단계별 서사를 씁니다. Palletto는 “이 화면이 어떻게 생겼고 얼마나 빽빽한가”가 곧 구매 판단 근거라, 마케팅 카피 대신 실제 대시보드 조각을 그대로 보여 줍니다. 번호 매김(01–05 사이클)은 루프처럼 실제 순서가 있는 곳에만 썼습니다.

06

모션

루프

히어로의 파렛트 스택이 천천히 위아래로 드리프트. 장식적 생동감. prefers-reduced-motion에서 정지.

Palletto

전환(hover) 외에는 움직임 없음. 라이브 표시등·중요 수치도 깜빡이지 않음.

왜 — 루프에서 약간의 움직임은 첫인상에 활기를 더합니다. Palletto에서는 정반대입니다. 주변 시야의 움직임은 계속 주의를 끌어당기고, 8시간이면 피로가 누적됩니다. 그래서 “중요한 것일수록 가만히 둔다”를 원칙으로 삼았습니다.
