# 명리 30일 — 하루 한 강, 내 사주로 배우는 명리학

30일 동안 하루에 한 강씩 명리학 기초를 익히는 정적 웹 서비스입니다. 빌드 없이 순수 HTML + CSS + 바닐라 JS로 동작합니다.

매일 강의는 네 부분으로 되어 있습니다.

1. **추천 영상**: 그날 주제의 유튜브 영상
2. **오늘의 핵심 정리**: 요점 3~5줄과 용어 정리
3. **내 사주에 적용해 보기**: 입력한 생년월일시로 그날 배운 내용을 바로 확인
4. **확인 문제**: 한 문제 퀴즈

## 구성

```
myeongri30/
  index.html          # 화면 뼈대 (상단 메뉴: 오늘 / 커리큘럼 / 내 사주)
  assets/data.js      # 콘텐츠: WEEKS·DAYS(30강) + 일간·오행·십신·12운성·궁위 해석 문구
  assets/app.js       # 화면 그리기, 진도 저장, 사주 분석(강약·용신·조후·합충·신살·격국)
  assets/charts.js    # 그림(SVG): 오행 상생·상극 다이어그램, 30일 진도 링, 강약 게이지, 음양 막대, 대운 타임라인, 12지지 계절 바퀴
  assets/manse.js     # 만세력 엔진 (saju/js 엔진을 일반 스크립트로 묶은 사본)
  assets/styles.css   # CSS 변수 + [data-theme="dark"] 다크 모드, 오행 색
  .nojekyll
```

## 화면

- **오늘** (`#today`): 진도율, 오늘의 강의(시작일로부터 N일째), 이어서 공부할 강의, 내 사주 요약, 4주 달력
- **커리큘럼** (`#list`): 4주 30강 목록, 공부 시작일 변경, 진도 초기화
- **강의** (`#day-1` ~ `#day-30`): 영상 · 핵심 정리 · 내 사주 적용 · 확인 문제 · 완료 체크
- **내 사주** (`#saju`): 양력/음력(윤달) · 시간 모름 · 성별 · 출생지 입력 → 원국표, 종합 해석, 각 항목에서 해당 강의로 이동

| 주차 | 내용 |
| --- | --- |
| 1주차 · 사주의 재료 | 사주팔자 구조, 음양, 오행, 상생상극, 천간, 지지, 60갑자·만세력 |
| 2주차 · 나와 십신 | 일간, 지장간, 십신 개요, 비겁·식상·재성·관성·인성 |
| 3주차 · 사주의 구조 | 월령·득령, 신강·신약, 오행 과다·결핍, 12운성, 합, 충·형, 용신, 조후 |
| 4주차 · 운의 흐름과 종합 | 대운, 세운, 신살, 격국, 궁위, 종합 해석 실습, 공부 이어가기 |

## 추천 영상 넣기

30강 모두 그날 주제에 맞는 유튜브 강의 영상이 하나씩 들어 있습니다. 강의 페이지 안에서 바로 재생되고, 아래에 제목·채널과 '같은 주제 다른 영상 찾기' 검색 링크가 붙습니다.

- 2026-11-24에 주제별로 검색해 고르고, 유튜브 oEmbed로 **영상이 존재하고 외부 사이트에서 재생(임베드)할 수 있는지** 30개 모두 확인했습니다. 임베드가 막힌 영상은 다른 영상으로 바꿨습니다.
- 영상 내용을 직접 시청해 검수한 것은 아닙니다. 제목과 설명이 그날 주제와 맞는 영상을 골랐으니 수업에 쓰기 전에 한 번 훑어보세요.
- 핵심 정리는 특정 영상의 요약이 아니라 이 사이트가 따로 정리한 강의 내용입니다.
- 영상이 삭제되거나 비공개로 바뀌면 플레이어에 오류가 뜹니다. 그때는 `assets/data.js` 의 해당 Day를 바꾸세요.

```js
video: "XXXXXXXXXXX",            // 영상 ID 또는 watch / youtu.be / shorts 주소
videoTitle: "영상 제목", videoChannel: "채널 이름",
```

`video` 를 `""` 로 비우면 그날 `query` 검색어로 유튜브 검색 버튼이 대신 나옵니다.
`file://` 로 열면 유튜브 임베드가 막힐 수 있습니다. 그때는 '유튜브에서 열기' 링크를 쓰거나 GitHub Pages / 로컬 서버에서 확인하세요.

## 내용 수정

- 강의 문구, 퀴즈, 검색어: `data.js` 의 `DAYS`
- 일간·오행·십신 해석 문구: `data.js` 의 `DAY_MASTER_TEXT`, `ELEMENT_TEXT`, `TEN_GOD_TEXT`
- 각 강의의 '내 사주에 적용' 상자 종류: `DAYS[].apply` (`app.js` 의 `APPLY` 함수 이름. `tenGods:재성` 처럼 `:` 뒤에 십신 묶음을 지정)

## 사주 계산과 해석 기준

- 만세력은 `saju/` 폴더 엔진을 그대로 옮겼습니다. 입춘·절입 기준 연월주, 지방시(경도) 보정, 서머타임, 1954~61년 UTC+8:30, 23시 자시 처리, 음력 변환을 반영합니다. 원본 검증 케이스 39건(외부 엔진 대조 30건 포함)이 묶음본에서도 모두 일치합니다.
- 엔진을 고쳐야 하면 `saju/js` 원본을 고친 뒤 같은 방식(ES 모듈 4개 → 함수 스코프로 감싼 일반 스크립트 하나, `window.Manse`)으로 다시 묶어야 합니다.
- **강약**: 월지 3 · 일지 2 · 나머지 1 가중치로 비겁+인성 비율. 60% 이상 신강, 40% 이하 신약.
- **용신**: 억부법만 씁니다(신강 → 식상·재성·관성, 신약 → 인성·비겁 중 원국에 가장 적은 오행).
- **조후**: 월지 계절 기준(여름 → 水, 겨울 → 火, 寅월 → 火, 申월 → 水).
- **격국**: 월지 지장간 중 천간에 드러난 것을 먼저 보고(정기 > 중기 > 여기), 없으면 정기로 정합니다.
- **신살**: 연지·일지 삼합 기준 도화·역마·화개.
- 모두 학습용 간이 판정입니다. 화면에도 참고 자료라는 안내를 넣었습니다.
